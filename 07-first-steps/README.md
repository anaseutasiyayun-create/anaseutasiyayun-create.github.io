# Первые учебные проекты (3 курс)

Проекты учебной практики (ГАПОУ «ОКЭИ», март–июнь 2024): первые шаги в HTML/CSS и основы Python.

## 🌿 landing/ — «Зелёный дом»

Первая адаптивная страница: магазин комнатных растений.

- Семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `footer`
- Раскладка на Flexbox, карточки переносятся сами (`flex-wrap`)
- Медиазапрос для телефонов, таблица доставки
- Без JavaScript: все анимации на чистом CSS — «дышащие» органические формы (`border-radius` в keyframes), качающиеся растения, падающие листья, горшок нарисован через `clip-path`
- Появление блоков при прокрутке тоже без JS: `animation-timeline: view()` (в браузерах без поддержки блоки просто видны)

Запуск: открыть `landing/index.html`.

## 🐍 python/ — основы Python

| Файл | Что делает | Что отрабатывала |
|---|---|---|
| `expenses.py` | Консольный учёт расходов: добавление, список, статистика с текстовой диаграммой, удаление | функции, списки и словари, циклы, `try/except`, работа с JSON-файлом |
| `password_check.py` | Проверка надёжности пароля с советами и генератор паролей | строки, условия, генераторы, модули `string` и `secrets` |

Запуск (Python 3.8+):

```bash
python python/expenses.py
python python/password_check.py
```
