TaskBoard — канбан-доска

REST API на Node.js + Express и одностраничный фронтенд на чистом JavaScript. Задачи можно перетаскивать между колонками, данные хранятся в JSON-файле или MySQL.

Открыть демо-версию → Работает без сервера: API имитируется в браузере.

Возможности

  • Три колонки: «К выполнению», «В работе», «Готово»; лимит задач в работе с предупреждением
  • Перетаскивание карточек (HTML5 Drag & Drop) с оптимистичным обновлением и откатом при ошибке
  • Плавный перенос карточек на новое место (FLIP-анимация, Web Animations API)
  • Создание, редактирование и удаление задач в модальном окне <dialog>
  • Приоритеты, теги, исполнители, дедлайны с подсветкой «скоро» и «просрочено»
  • Фильтры по приоритету, тегу и исполнителю, поиск с debounce, прогресс выполнения
  • Светлая и тёмная тема, работа с клавиатуры: N, /, T, ← →
  • Два хранилища с одинаковым интерфейсом: JSON-файл или MySQL
  • Валидация на сервере и unit-тесты валидатора (node --test)

REST API

Метод URL Описание
GET /api/tasks Список задач, фильтры ?status=todo&tag=js&q=...
GET /api/tasks/:id Одна задача
POST /api/tasks Создать задачу
PATCH /api/tasks/:id Изменить часть полей
DELETE /api/tasks/:id Удалить задачу
GET /api/stats Количество задач по статусам

Запуск

Нужен Node.js 18+. Проект работает с сервером, поэтому открывается локально:

npm install
npm start      # http://localhost:3000
npm test       # тесты валидации
