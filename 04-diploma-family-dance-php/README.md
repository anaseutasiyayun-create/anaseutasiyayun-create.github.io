# Family Dance — сайт школы танцев (дипломный проект)

Дипломная работа по специальности «Программист, разработчик веб и мультимедийных приложений» (ГАПОУ «ОКЭИ», 2025). Тема: сайт школы танцев «Family Dance», Оренбург.

Адаптивный сайт с направлениями и расписанием занятий из базы данных, онлайн-записью на пробный урок и админ-панелью для администратора школы. Контент (направления, расписание, цены, контакты) взят из сообщества школы ВКонтакте, стиль — из фирменной айдентики: тёмный фон, яркие акценты и рукописные надписи.

## Демо без сервера

Папка `demo` открывается двойным кликом, без PHP и MySQL:
- `demo/index.html` — сайт; форма записи работает, заявки сохраняются в браузере;
- `demo/admin.html` — демо-админка (вход `admin` / `admin123`): заявки с фильтрами и сменой статуса, расписание с добавлением, скрытием, удалением и проверкой пересечений по залам.

## Как запустить

Дважды кликните **`start.bat`**. Скрипт сам:
1. найдёт PHP и MariaDB/MySQL (установлены через winget или XAMPP);
2. запустит сервер базы данных, если он не запущен;
3. при первом запуске создаст базу `family_dance` из `schema.sql`;
4. откроет сайт: http://localhost:8000

Админка: http://localhost:8000/admin/ — логин `admin`, пароль `admin123` (тестовые данные, смените после установки).

Пока открыто окно сервера, сайт работает; чтобы остановить, закройте окно.

Нужны PHP 8.1+ (расширения `pdo_mysql`, `mbstring`) и MariaDB или MySQL:
```
winget install PHP.PHP.8.3
winget install MariaDB.Server
```

## Возможности

**Сайт**
- Направления из БД с фильтром «для детей / подростков / взрослых»
- Карточка направления в модальном окне: описание, дни и время занятий из БД, кнопка записи
- Запись на пробный урок: проверка на клиенте (JS) **и** на сервере (PHP), отправка через `fetch`, ответ в JSON
- Серверные проверки: возраст ученика подходит к выбранному занятию, занятие ещё проводится, не больше 3 заявок с одного номера в сутки
- Цены, «Что надеть», отзывы, FAQ, контакты с картой и соцсетями
- Шрифты подключены без блокировки отрисовки: страница работает, даже если Google Fonts недоступен

**Админ-панель** (`/admin`)
- Вход по логину и паролю (`password_hash` / `password_verify`, `session_regenerate_id`)
- **Заявки:** статистика, диаграмма интереса по направлениям, поиск по имени и телефону, фильтры, смена статуса (новая → связались → пробное → занимается / отказ)
- **Расписание:** полный CRUD, скрытие с сайта, счётчик заявок на занятие, запрет двух занятий в одном зале в одно время

**Безопасность**
- Подготовленные запросы PDO против SQL-инъекций
- Экранирование вывода (`htmlspecialchars`) против XSS
- CSRF-токены во всех формах

## Схема БД

```
directions   (id, name, name_ru, slug, description, ages, audience SET, price, sort)
schedule     (id, direction_id → directions, weekday, start_time, duration,
              min_age, max_age, level ENUM(beginner, pro, kids), hall, is_active)
applications (id, name, phone, student_age, direction_id → directions, schedule_id → schedule,
              comment, status ENUM(new, contacted, trial, enrolled, cancelled), created_at)
admins       (id, login, password_hash)
```

Расписание в `schema.sql` разворачивается из записей вида «Пн-Ср-Пт в 17:00» одним `INSERT … SELECT` с `JOIN` по дням недели.

## Видео направлений

В окне направления играет видео (без звука, со звуком — через панель плеера). Ролики лежат в `assets/video` под slug направления: `choreo`, `girlchoreo`, `heels`, `jazzfunk`, `contemporary`, `modern` — MP4 720p (H.264, около 5–8 МБ) и кадр-обложка `.jpg`. Если файла нет, в окне показывается фото или заглушка. Новое видео сжимается так:

```
ffmpeg -i исходник.mp4 -vf "scale='if(gt(iw,ih),1280,720)':-2" -c:v libx264 -crf 28 -preset slow -movflags +faststart -c:a aac -b:a 96k assets/video/slug.mp4
```

> Номера залов в расписании условные: в сообществе школы не указано, в каком зале проходит каждое занятие.
