# Учебные проекты на JavaScript

Серия проектов учебной практики (ГАПОУ «ОКЭИ», 4 курс, сентябрь–декабрь 2024). Каждый проект закрывает отдельную тему.

| Проект | Что отрабатывала |
|---|---|
| [Список дел](todo/) | CRUD на массиве объектов, делегирование событий, localStorage, фильтры, редактирование двойным кликом, защита от XSS через `textContent` |
| [Учёт расходов](expenses/) | Форма с проверкой данных, группировка и подсчёт сумм через `filter` и `reduce`, сводка по категориям с диаграммой, фильтр по месяцу, удаление с возможностью отменить, localStorage |
| [Калькулятор](calculator/) | Объект состояния, цепочки операций, деление на ноль, погрешность float (`0.1 + 0.2`), управление с клавиатуры, история вычислений |

## Стек

HTML5, CSS3 (Grid, Flexbox), JavaScript ES6+, localStorage, Git.

## Запуск

Откройте `index.html` в браузере — с него есть ссылки на все проекты. Каждый проект — один HTML-файл без библиотек.
