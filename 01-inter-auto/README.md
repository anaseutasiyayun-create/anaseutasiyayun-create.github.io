# Интер-Авто АКПП — сайт автосервиса

Коммерческий проект: сайт специализированного автотехцентра в Оренбурге, который ремонтирует АКПП, DSG и CVT. Я сделала его с нуля: структура, пользовательские сценарии, вёрстка, интерактив, тестирование на разных устройствах и публикация. Все этапы согласовывала с заказчиком.

## Что сделано

- Адаптивная и кроссбраузерная вёрстка: desktop / tablet / mobile (Flexbox, Grid, медиазапросы)
- Мобильное меню: закрывается по клику вне меню, по Esc и при переходе на широкий экран; есть `aria-expanded`
- На телефоне снизу закреплена панель с кнопками «Позвонить» и «Написать»
- Блоки появляются при прокрутке (IntersectionObserver), карточки — по очереди
- Лёгкий параллакс у фото первого экрана, тень у шапки при прокрутке
- Подсветка текущего раздела в меню
- У длинных отзывов кнопка «Читать полностью»; она появляется, только если текст действительно обрезан
- Интеграции с Яндекс Бизнесом: виджет рейтинга, карта с карточкой организации, ссылка на отзывы
- Иконки собраны в SVG-спрайт: один набор `<symbol>`, без лишних запросов

## Оптимизация

- Изображения грузятся лениво (`loading="lazy"`, `decoding="async"`), первый экран — в формате WebP
- Google Fonts подключены без блокировки отрисовки; если шрифт недоступен, текст показывается системным шрифтом
- Анимации отключаются при `prefers-reduced-motion`
- Без библиотек и фреймворков, весь JavaScript — около 5 КБ

## Стек

HTML5, CSS3, JavaScript ES6+, Git, Яндекс Облако (Object Storage + CDN).

## Запуск

Откройте `index.html` в браузере. Сборка не нужна. Виджеты Яндекса (рейтинг и карта) работают только при подключении к интернету.
