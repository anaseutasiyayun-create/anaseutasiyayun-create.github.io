# SHUKLINA — сайт фотографа

Сайт-портфолио фотографа Людмилы (Instagram [@ph_shuklina](https://www.instagram.com/ph_shuklina/)), Оренбург. Love story, портреты и семейные съёмки в естественной обработке. Фронтенд на чистом HTML, CSS и JavaScript, без библиотек.

## Разделы

- **Первый экран** с видео на фоне и кнопкой записи
- **Серии** — истории съёмок: вертикальная прокрутка двигает ленту карточек по горизонтали
- **«Без кукольного эффекта»** — слайдер сравнения «цвет ↔ ч/б»
- **Работы** — галерея с фильтром и лайтбоксом
- **Обо мне** — видео, которое играет, только когда его видно на экране
- **Стоимость** и **Как проходит съёмка**
- **Запись** — переход в личные сообщения Instagram

## Что реализовано

- Адаптивная вёрстка, шапка меняет цвет после первого экрана
- Плавное появление блоков при прокрутке (IntersectionObserver)
- Горизонтальная лента серий, управляемая обычной прокруткой страницы
- Слайдер сравнения двух версий фото
- Фильтр галереи и лайтбокс для галереи и серий
- Круглый курсор «Смотреть» над фотографиями
- Видео на первом экране не проигрывается при `prefers-reduced-motion`
- Фото в формате WebP, видео в «Обо мне» не тратит ресурсы, пока его не видно

## Стек

HTML5, CSS3, JavaScript ES6+, Git.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна. Все фото и видео лежат в папке `photos`.
