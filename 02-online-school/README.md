# CodeStart — лендинг онлайн-школы программирования

Адаптивный лендинг для онлайн-школы программирования для подростков. Сделан с нуля: анализ требований, структура, дизайн, вёрстка и деплой на GitHub Pages.

## Функциональность

- **Слайдер отзывов** написан как ES6-класс: 1/2/3 слайда в зависимости от ширины экрана, стрелки, точки, перетаскивание мышью и свайп, управление стрелками клавиатуры
- **Аккордеон FAQ** с плавной анимацией высоты и `aria-expanded`
- **Форма заявки с валидацией на JS**: имя, телефон, email (регулярные выражения), возраст 10–17, согласие; ошибки показываются при потере фокуса и при отправке, фокус переходит на первое ошибочное поле
- Фильтр курсов по возрасту; клик по курсу подставляет его в форму
- Эффект «печатающегося кода» в первом экране
- Таймер до конца набора с правильными склонениями (1 день / 2 дня / 5 дней)

## Оптимизация

- Нет картинок в первом экране — только CSS и текст
- Шрифты подключаются с `preconnect` и `display=swap`
- Скрипт подключён в конце `body`, без библиотек

## Стек

HTML5, CSS3 (Grid, Flexbox, custom properties, `color-mix`), JavaScript ES6+ (классы, async/await), Git, GitHub Pages.

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите файлы проекта.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root`.
3. Свой домен: добавьте файл `CNAME` с доменом и CNAME-запись `<username>.github.io` у регистратора.
